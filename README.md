# Salut 👋

Bienvenue sur mon GitHub.

J'aime construire des outils concrets : **automatisation, Python / JavaScript, plotter art et fabrication numérique**. La plupart de mes projets partent d'un besoin réel — dessiner avec un traceur, piloter une IA locale, organiser ses fichiers ou créer un site pour un atelier.
